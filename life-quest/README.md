# LIFE QUEST

Персональная RPG для сбалансированного развития восьми сфер жизни: здоровье, деньги, мастерство и работа, отношения, быт, автономия, радость и восстановление.

## Запуск

Откройте **https://giorgiopagani1.github.io/preview/life-quest/** в браузере. Это статический HTML, без сборки и установки зависимостей.

## Как играть

- Выберите режим: обычный, облегчённый или день защиты.
- Отмечайте короткие квесты. Пропуск не штрафуется.
- Следите за балансом сфер, а не за максимальным числом баллов.
- В разделе «Дневник» записывайте наблюдения и экспортируйте сохранение.

## Конфиденциальность

Прогресс, записи дневника и режимы сохраняются в `localStorage` вашего текущего браузера. На GitHub они **не отправляются** и не синхронизируются между устройствами. Используйте экспорт/импорт JSON, если нужно перенести данные. Не выкладывайте файлы сохранений в публичный репозиторий.

## Принципы безопасности

Игра не поощряет рискованные финансовые операции. Сон, питание, безопасность, здоровье и реальные отношения важнее любых очков. Для дней высокой нагрузки предусмотрен режим защиты.

## Технические детали

Приложение полностью расположено в `index.html` и работает без сервера, API-ключей и внешних зависимостей.
