# Турбомозг — Phaser 3

Играбельный мобильный прототип образовательной аркады для детей 6–12 лет.

**Запуск:** https://giorgiopagani1.github.io/preview/turbomozg/

## Состав

- `index.html` — автономная веб-сборка игры: JavaScript, логика, оформление и графические ресурсы встроены в HTML.
- Используется движок **Phaser 3.90.0**, загружаемый через cdnjs. Для запуска требуется интернет.

## Игровой процесс

16 математических заданий, затем три этапа битвы с боссом; таймер, три жизни, возраста 6–8 / 9–12 лет, музыка и усиленные эффекты комбо. На комбо ×12 ошибка сбрасывает серию без потери жизни.

## Разработка

Рабочие исходники проекта доступны в ZIP-архиве, приложенном в чате. Этот каталог содержит опубликованную сборку для GitHub Pages; существующие страницы репозитория не затронуты.
